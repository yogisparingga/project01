# Game Matematika

Game matematika interaktif berbasis web untuk melatih kemampuan berhitung Anda!

## Fitur

- **3 Tingkat Kesulitan**
  - **Mudah**: Angka 1-20, operasi penjumlahan dan pengurangan
  - **Sedang**: Angka 1-50, operasi penjumlahan, pengurangan, dan perkalian
  - **Sulit**: Angka 1-100, semua operasi matematika (termasuk pembagian)

- **Sistem Scoring**: Dapatkan poin berdasarkan kecepatan menjawab
- **Timer**: Setiap pertanyaan memiliki batas waktu
- **Progress Bar**: Lihat progres permainan Anda
- **Feedback**: Pesan motivasi berdasarkan performa Anda

## Cara Bermain

1. Buka file `index.html` di browser web Anda
2. Pilih tingkat kesulitan (Mudah, Sedang, atau Sulit)
3. Jawab 10 pertanyaan matematika dengan cepat dan tepat
4. Lihat skor akhir Anda dan coba lagi untuk meningkatkan!

## Cara Menjalankan

```bash
# Buka dengan browser langsung
open index.html

# Atau gunakan server lokal (contoh dengan Python)
python -m http.server 8000
# Kemudian buka http://localhost:8000
```
